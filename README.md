# Steam-Property-Calculator-Python
Python-based thermodynamic calculator for water and steam properties using IAPWS-IF97 standard with phase detection, T-s and h-s diagrams, and GUI interface.

A Python-based desktop application for calculating thermodynamic properties of water and steam using the IAPWS-IF97 standard.

## Overview

This project provides a graphical tool for engineering thermodynamics calculations. It calculates water and steam properties based on different input conditions and automatically identifies the thermodynamic phase.

## Features

- Water and steam property calculation using IAPWS-IF97 standard
- Support for multiple input combinations:
  - Pressure & Temperature (P-T)
  - Pressure & Quality (P-x)
  - Temperature & Quality (T-x)
  - Pressure & Specific Volume (P-v)
  - Pressure & Enthalpy (P-h)
  - Pressure & Entropy (P-s)
  - Temperature & Entropy (T-s)

- Automatic phase detection:
  - Compressed Liquid
  - Saturated Liquid
  - Two-Phase Region
  - Saturated Vapor
  - Superheated Steam

- Thermodynamic diagram visualization:
  - T-s Diagram
  - h-s Diagram

- Export calculation results to PDF
- Graphical user interface developed with Tkinter

## Technologies and Libraries

- Python
- IAPWS
- NumPy
- Matplotlib
- Tkinter
- ReportLab

## Engineering Applications

This tool can be used for:
- Thermodynamics education
- Steam cycle analysis
- Engineering calculations
- Water and steam property evaluation
